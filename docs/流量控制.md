# 流量告警、压缩缓存与限速

网站采用三层措施：云平台监控月流量包，Nginx 减少静态资源传输，入口按来源 IP 限制高频请求。告警用于提醒，Nginx 限速用于控制请求频率，两者都不提供费用封顶保证。

## 月流量包告警

腾讯云控制台路径：腾讯云可观测平台 → 告警管理 → 告警配置。策略类型选择“轻量应用服务器-网络流量包”，对象绑定自己的实例。该指标是**剩余量百分比**，以下三档对应一个月流量包为 300 GB 的示例：

| 已使用 | 大约已用量 | 剩余量触发条件 | 告警级别 |
|---|---|---|---|
| 50% | 150 GB | 剩余量 ≤50% | 提示 |
| 80% | 240 GB | 剩余量 ≤20% | 严重 |
| 90% | 270 GB | 剩余量 ≤10% | 紧急 |

可在同一指标上启用“告警分级”，分别填写三档阈值。统计粒度设为 1 分钟，持续 1 个数据点，按需选择只告警一次；通知模板应覆盖全部启用的告警级别，并绑定实际接收人。保存后检查策略详情、对象及通知配置。未实际触发前，配置检查不能证明消息已经送达。

依据：[腾讯云分级告警配置](https://cloud.tencent.com/document/product/248/102708)、[默认流量包指标说明](https://cloud.tencent.com/document/product/248/99182)。

## 静态资源压缩与缓存

配置位于 `deploy/linux/nginx-https.conf`，随 HTTPS 站点模板安装：

- JavaScript、CSS 和 SVG 使用 gzip，压缩级别 5；较小的响应按阈值跳过压缩。
- Vite 的 `/assets/` 文件名包含内容哈希，响应带 `public, max-age=31536000, immutable`，可缓存一年；新版本使用新的文件名。
- `favicon.svg` 缓存一天；HTML 设置 `no-cache`，浏览器复用前需要验证更新，及时获取新版本的资源地址。
- API 保持后端的 `Cache-Control: no-store`，关闭动态响应压缩；账号和会话响应不会使用静态资源缓存策略。

2026-11-17 实测：两份主要 JS/CSS 原始正文合计 188,949 字节，gzip 后 64,219 字节，减少约 66%。携带 `If-Modified-Since` 的资源请求返回 304。该数值只比较本次构建的静态资源正文，不包含 API、HTTP/TLS 开销。

依据：[Nginx gzip](https://nginx.org/en/docs/http/ngx_http_gzip_module.html)、[响应头与缓存控制](https://nginx.org/en/docs/http/ngx_http_headers_module.html)。

## 按来源 IP 限速

| 入口 | 持续速率 | 短时突发余量 |
|---|---|---|
| HTTPS 页面 | 每秒 5 次 | 10 次 |
| 静态资源 | 每秒 20 次 | 40 次 |
| 普通 API | 每秒 10 次 | 20 次 |
| 登录接口 | 每分钟 10 次 | 10 次 |

这些值是漏桶限速参数，允许短时突发，不表示每个自然秒或自然分钟的严格次数上限。每个来源 IP 同时处理的活动连接上限为 20。超过限制返回 HTTP 429；响应提供 JSON 提示、`Retry-After: 6` 和 `Cache-Control: no-store`。应用原有的按账号连续登录失败限制继续生效。

当前服务器由客户端直接连接 Nginx，限制键使用连接来源 IP。若以后添加 CDN 或反向代理，需要先按可信代理范围配置真实客户端 IP；同一校园或公司出口下的用户会共享 IP 额度，人数增加时根据实际情况调整。

HTTPS 入口的限速检查位于处理请求阶段，不能消除所有攻击流量，也不能阻止分布式来源消耗流量。证书验证路径保持可用；普通 HTTP 请求只跳转到 HTTPS。

依据：[Nginx 请求限速模块](https://nginx.org/en/docs/http/ngx_http_limit_req_module.html)。

## 修改、检查与回退

修改站点模板后，替换服务器站点配置中的 IP 占位符，先备份旧配置，再执行 `sudo nginx -t`，成功后 `sudo systemctl reload nginx`。配置校验或重载失败时恢复旧文件。只修改 Nginx 无需重新打包 Java 应用。

验收应检查：静态资源 gzip 与缓存头、HTML 更新策略、API 禁止缓存、普通登录与读取、短时间高频请求返回 429、等待后恢复。云端验收脚本显式放慢请求及登录频率，以避免入口限速干扰应用层账号安全测试。
